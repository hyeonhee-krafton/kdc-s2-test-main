# kdc-s2-test

## KDC Club Season2 종료파티에 사용된 클러버 성향 테스트 입니다. 
총 17종의 성향 결과를 받아보실 수 있습니다. 

4축 설계, 12개의 문항을 통해 나의 캐릭터와 강점, 
시너지 캐릭터(약점 보완&강점 강화) 까지 확인해보세요! 

나와 맞는 클럽도 추천받을 수 있습니다 :) 

현장에서는 결과 캐릭터가 포함된 커스텀 카드를 배부드립니다.
